# AI Productivity Hub

Build a modern, responsive web application called "AI Workplace Productivity Assistant" that helps professionals automate workplace tasks using AI.

The application should include these 5 features accessible via a sidebar:

1. Smart Email Generator

2. Meeting Notes Summarizer

3. AI Task Planner

4. AI Research Assistant

5. AI Chatbot Interface

Requirements:

- Modern SaaS-style dashboard UI with a clean, professional color scheme

- Sidebar navigation with icons for each feature

- Responsive design (works on desktop and mobile)

- Each feature page has a clear INPUT section and OUTPUT section

- AI outputs should be displayed in editable text areas

- A persistent Responsible AI disclaimer in the footer

- Use shadcn/ui components and Tailwind CSS

- Add a welcome/dashboard home page that introduces the app
