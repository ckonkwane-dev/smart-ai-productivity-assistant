# AI Workplace Productivity Assistant

## Build
- Apply the selected Editorial Ink visual system with responsive, collapsible navigation and a persistent Responsible AI footer.
- Create a dashboard plus dedicated Email, Meeting Notes, Task Planner, Research, and Chat views.
- Give every tool a clear input area, editable output, copy controls, loading feedback, and useful empty/error states.

## AI and data
- Connect all five tools to Lovable AI with streamed chat and server-side one-shot workflows.
- Keep one ongoing chat and save its completed messages in Lovable Cloud, scoped to the signed-in user.
- Add a simple email/Google sign-in experience so Cloud-saved chat stays private.

## Technical details
- Use TanStack Start routes, shadcn/ui, Tailwind v4 semantic tokens, and AI Elements primitives.
- Add row-level access rules and explicit database grants for the saved conversation.
- Verify desktop/mobile layouts, key tool flows, chat persistence, metadata, and current diagnostics.
